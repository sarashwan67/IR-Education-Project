# IR Education Project

Information Retrieval Project - Education Domain.

## Project Description

This project focuses on building an Information Retrieval system
using educational documents.

## Project Structure

- data: Contains the text documents.
- src: Contains the project source code.
- output: Contains the processed data.

## Technologies Used

- Python
- Apache Spark (PySpark)
- Pandas

## Installation

Install the required libraries:

pip install -r requirements.txt

## Run the Project

python src/prepare_documents.py
